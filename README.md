# Hall Effect Sensor Simulation
A computational simulation demonstrating the principles of the Hall Effect, visualizing how a magnetic field applied perpendicular to an electrical current induces a measurable transverse voltage across a conductor or semiconductor.    Overview This project provides an interactive simulation to help users understand the physical mechanisms behind Hall Effect sensors, which are widely used for proximity switching, positioning, speed detection, and current sensing applications. The Physics Behind the Simulation The simulation is built upon the fundamental Hall Effect equation. When a magnetic field is applied perpendicular to the current flow, it exerts a Lorentz force on the charge carriers, pushing them to one side of the material and creating a measurable voltage difference:$$V_H = \frac{I \cdot B}{n \cdot e \cdot t}$$Where:$V_H$ = Hall voltage$I$ = Current flowing through the material (Amperes)$B$ = Magnetic field strength (Teslas)$n$ = Charge carrier density of the material$e$ = Elementary charge ($1.602 \times 10^{-19}$ Coulombs)$t$ = Thickness of the material
